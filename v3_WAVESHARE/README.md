# v3 Waveshare ESP32-S3 Audio Board

Target workspace for the ESP32-S3 audio-board iteration.

Planned stack:

- ESP-IDF project structure.
- Onboard microphones, codec, speaker path, and RGB LED ring.
- Optional SPI TFT and camera experiments after the audio loop is stable.
- App or network bridge for LLM API calls, with local device UI feedback.

Start here once the first ESP-IDF prototype is added.
