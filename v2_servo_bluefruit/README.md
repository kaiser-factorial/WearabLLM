# v2 Servo Bluefruit Archive

This folder is reserved for the servo-era Bluefruit experiment: servo actuation, audio clips, mechanical files, and related app/code snapshots.

The local copy currently contains macOS/iCloud placeholder files and generated dependency folders, so the full archive is intentionally ignored in Git until the readable source/assets are restored or curated.

Keep this version as historical reference only. The active direction is the ESP32-S3 audio-board build documented in `../SPEC.md` and `../HARDWARE.md`.
